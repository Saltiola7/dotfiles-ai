activate only exact qualified installed combination. No dependency installation

quiescence assertion and incompatible-client exclusion prerequisites. Exercise
original-digest replay with verified original bytes/hash, intent, custody and exact

conflict refuses, post-terminal reassignment retains pointer and blocks registration.

## Exact nominated recovery

Keep cycle ID, repository paths, stash/WIP identity, raw inventories and approvals
only in existing private evidence. Before production mutation, operator nominates
exact repository/cycle and tooling produces fresh preview. Earlier anecdotal
cleanliness or equality is not current proof. Verify actual recorded/import/Git
object closure, pointer and branch identity, dirty/index/ignored/DVC obligations,
private approval/evidence references and consumers.
Explicitly verify old writers stopped and incompatible clients kept out before
closure; missing operation history is not inactivity proof. A held lock or positively
identified live writer blocks despite operator assertion.

Obtain separate exact approvals for installed activation, record retirement,
archive capture, any native consumer shutdown/restart, and preparation/removal.
Approval may cover one fully enumerated capture/preparation/removal plan, but never
implies future drift or additional files. Use supported CLI only. Original failed
gates and uncertainty remain; no ledger editing or manufactured success.

Success requires terminal administrative outcome, unchanged original evidence,
verified local restore, no live consumers, native hooked removal with unchanged
retained branch, and historical status readable without checkout. If a step fails,
retain exact observed progress and archive; show supported next action. Do not
undo successful closure/session movement to make sequence appear atomic.

## Rollback and operation

Retain installed preimages and newly written records/refs/archives. Rollback may
disable new mutations/instructions while retaining a reader capable of new
retirement/archive metadata; never reinstall an incompatible writer or relabel
records. No archive/ref deletion, Git reset, branch swap or cache GC. Restore to a
new empty recovery destination, not over an existing checkout with user edits.

Monitor bounded status/reason classes, partial preparation and retained consumers.
No raw paths, payloads, private user identity or project content enters public
completion notes. A missing/denied capability is an explicit unresolved result.
Review archive retention only under separate future operator scope.
