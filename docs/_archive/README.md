# Documentation Archive

This directory contains historical source retained for provenance. It is not
deployed and must not be followed as current operational guidance.

- `opencode/skills/v2/` preserves DBSCTR V2 and Discovery2 source history.
- Current lifecycle entry points are `/discovery`, `/dbsctr`, and `/qa`.
- Current lifecycle authority is
  [`docs/specs/dbsctr_v3_lifecycle/`](../specs/dbsctr_v3_lifecycle/); Method
  Revision 3.27 remains compatible with older V3 records.

Completed cycle-start plans may also live in an owning bounded context's
`_archive/` directory. They record gate applicability at cycle start, not final
Gate Results; the context README, BACKLOG, and CHANGELOG remain authoritative.
