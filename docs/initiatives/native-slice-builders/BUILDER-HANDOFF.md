# Worked handoff: a file format and its reader

The first increment is planning and routing guidance. It changes no
permission, enrollment, provider, installed runtime, or delivery mode.
It can ship independently of the writer and grant qualification.

| Slice | Target and write owner | Can start when | Evidence to release its dependent |
| --- | --- | --- | --- |
| Format | Format repository; one writer owns the schema and shared fixture | Its contract is approved and the target has capacity. | Its merged revision contains the reviewed fixture. A draft does not release the consumer. |
| Caption | Reader repository; one writer owns the caption dictionary | It needs no format changes. It can run alongside Format in another session. | The expected change is included in the reader target. |
| Combined behavior | Reader repository; one writer owns the adapter and its tests | Both prerequisite revisions are present and the reader target's slot is available. | Its own integration test passes and the selected delivery condition is met. |

Forking the conversation does not reserve a checkout. The durable controller
resolves the current claim, qualified writer, repository, worktree, branch,
base and owned paths before launch. If two slices need the same fixture
in one repository, add a dependency or assign it to one owner. If only one
slice is runnable, recommend a single writer. A missing prerequisite blocks
only its dependent. An unresolved or lost claim is reconciled before retry.

**Available today:** Build can use ordinary native helpers for disjoint
edits, research and focused tests. Supply the actual readable checkout
and the owned paths. Leave Git, lifecycle and forge steps with the
authorized primary when the helper lacks them. A denied command or
directory is a capability result. Return findings or handoff text rather
than trying the operation through another tool. Plan remains read-only.

**After qualification:** bind each builder run to the slice and writer.
Return the original evidence reference, command/selection, time and result,
tested inputs, candidate tree, toolchain and environment. A trusted binding
for the same gate and inputs may be reused. Caption's unit test cannot
stand in for the combined integration test or required CI. Send failed CI
and its candidate/run identity to the writer with the applicable repair
limit. The original Auto controller updates the tally and enforces revocation
or a material scope change. No second controller starts from a child report.

**Acceptance for the first increment:** without an operator prompting to
delegate, a Discovery handoff explains the two independent writers and the
blocked consumer above, handles overlapping write sets, stays serial for
a single owner, identifies unavailable native tools, and carries the chosen
draft/other delivery boundary. Neither Build nor a fork infers launch,
review, gate or merge authority from that recommendation. Check the actual
managed instructions and role-routing regressions, including Plan.
