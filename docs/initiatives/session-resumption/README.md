  worktree allocation root before validating Git registration and the Cycle Record.

  A fresh conversation at the same location cannot change that directory predicate.

  Removing the core prefix check alone does not qualify managed child boundaries.

  of it. Setting tracking alone is not a verified local-Discovery delivery path.
  Approval binds manifest commit/blob and applicability plan as well as digest;
  unchanged manifest content alone does not prove approval survives relocation.
- DKS routing and host disablement are delivered, but irreversible state retirement
  is not. The existing retirement contract preserves PM evidence and ambiguous
  assets. A reported symlink rejection is not yet a proven validator defect.
- Inspection of the active retirement worktree through Bash was denied pending
  attachment. Do not use another tool to reproduce the denied operation or take
  over that cycle. Further private diagnostics require a permitted read-only path.
