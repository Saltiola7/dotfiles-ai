## Outcome

Operators obtain truthful source-local autonomous-runtime mean, p50, and p90
without scanning `opencode.db`, exposing private spans, or confusing missing
timing with zero.

## Context

Current cycle metrics measure calendar creation-to-completion time. Explicit
Phase Spans are sparse and may cover only a small fraction of a cycle, so current
history cannot establish autonomous-runtime trends or verify optimization.

## Scope

Implement the source-local `cycle-performance` JSON report defined by the cycle
performance specification. Reuse Cycle Records and the private phase ledger.
Preserve existing record and review compatibility.

Do not add OpenCode hooks, federation, DKS repair, execution concurrency, provider
tuning, a hosted service, or any gate reduction.

## Acceptance Criteria

- Complete helper timing produces interval-union autonomous runtime.
- Missing, incomplete, ambiguous, or overlapping timing remains unavailable and
  does not enter aggregates.
- Reports include integer mean, nearest-rank p50/p90, coverage, unavailable
  counts, and quality counters.
- Filters are validated and source-local; empty populations are truthful.
- The command never reads `opencode.db`, creates state during a read, or emits
  cycle IDs, ownership paths, detailed spans, or sensitive content.
- Existing records remain readable without migration.

## Evidence

Launch created a stale receipt-mismatched worktree before the Initiative's
Discovery commit reached the protected base. The worktree contains unrelated
uncommitted changes and remains preserved without cleanup or reuse. Delivery
continues under replacement ticket `V3.40-F1`.

## Risks

Incorrect interval arithmetic could double-count concurrency or hide pauses.
Focused overlap, nesting, malformed, empty, and compatibility tests fail closed.

## Review

Blocked without implementation. No unrelated worktree content was modified or
discarded.
