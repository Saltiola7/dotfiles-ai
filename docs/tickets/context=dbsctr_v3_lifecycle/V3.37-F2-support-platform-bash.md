## Outcome

The managed Graphify adapter parses and runs with the macOS platform Bash 3.2
used by GitHub Actions as well as newer managed Bash versions.

## Context

GitHub Actions run 33136035958 showed that Bash 3.2 parses backticks inside a
command-substitution heredoc differently from the managed Bash 5 runtime.

## Scope

Change only report-identity parsing syntax and add a platform Bash parser check.

## Acceptance Criteria

- Report identity validation avoids legacy Bash parsing of backticks inside a
  command-substitution heredoc and uses portable heredoc control flow.
- `/bin/bash -n` passes on the supported platform runtime.
- The adapter behavior suite passes unchanged.

## Risks And Recovery

The change only restructures existing failure control flow. Rollback restores the
V3.37-F1 helper after CI incompatibility is otherwise resolved.

## Evidence

Platform Bash parsing and successful adapter execution pass with the 33-test
adapter suite; focused controller Graphify tests also pass. The corrected managed
helper was applied locally and matches its managed source exactly.
The deployed helper passes `/bin/bash -n`; no release artifact or migration is
required. PR 58 merged as `32e325e`; post-merge reconciliation was conflict-free.

## Review

Independent review found no high or medium issues. Its low request for explicit
successful `/bin/bash` execution is covered by the platform-runtime regression.
