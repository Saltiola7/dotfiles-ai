# Codex native ownership

Resolve the actual Codex executable/version, process-selected home and native
configuration layers for the requested surface. CLI, Desktop and IDE can use
different homes and versions; environment labels and a shell directory change do
not bind or authenticate another running session.

Use native `codex mcp add/get/list/remove` where supported by the selected version
and the existing managed projector when one owns that configuration. Do not ban
the native writer because an upstream example prefers inline TOML. If a needed
forwarding/configuration feature is absent, use the owner's reviewed supported
path or report the gap; do not hand-edit an unrelated home or provider state.

Codex native MCP entries use `mcp_servers`, with a selected supported stdio
command/args or remote transport. Inspect the actual current schema/help and
allowlisted environment/secret controls; do not assume every Codex version
forwards all/no ambient variables or that user configuration universally overrides
project layers. Names must satisfy actual native validation. Existing same-name
entries are collisions unless their owner and complete target identity match.

For an authorized JFrog Agent Guard entry, use the already reviewed runtime/pin,
selected platform ID, exact package and non-secret `_JF_ARGS` per
[common preflight](agent-guard-common.md). Never store raw tokens, sign-in URLs or
private headers in portable config/arguments. Preserve unrelated tables, hooks,
trust and provider authentication. Native login/secret handling owns credentials.
Do not start OAuth, invoke `enable_*_tools`, self-grant project trust, change
sandbox/network policy or enable a plugin to complete registration.

Verify native entry discovery and actual upstream tool metadata separately.
A process/connected label or only an OAuth-enabling tool does not establish target
operation readiness. Restart only the selected surface when needed and authorized;
never replace the current task with a new client to evade unavailable permissions.
Retain private preimages and exact owner/version before changes or rollback.
