# Missing or old Node runtime

Node 18+ is required for the retained `.mjs` helpers. It is not a prerequisite for
planning, filesystem inspection or every JFrog CLI operation. Preserve the
project-selected/runtime installation owner. Report the specific missing helper
capability and continue independent authorized checks.

Do not run curl-to-shell/nvm, npm-global or winget bootstrap merely to complete
this workflow. Explicit runtime installation/update is separate owner work with
reviewed source/version, compatibility and rollback; it must not replace a
project's selected Node environment or broaden platform permissions.
