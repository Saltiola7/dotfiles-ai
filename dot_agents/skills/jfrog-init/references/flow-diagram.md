# Readiness flow

| Stage | Required guard and transition |
|---|---|
| Select requested capability | Actual JFrog task and known native/platform owner; unrelated setup remains out of scope. |
| Resolve prerequisite | Reuse explicit target/tool selection; ask only for material unresolved identity. |
| Review check effects | Transitive helper, credential/configuration access, network and writes are known; no detector-name assumptions. |
| Observe capability | Use authorized bounded native check; preserve real status and sanitized evidence. |
| Optional repair | Separate concrete authorized owner action; no auto-install, login, retarget or governance change. |
| Report | Independent observed pass/gap/failure; no setup-state write or invented global readiness. |

This table replaces the upstream automatic installer/authentication/marketplace
flow for the portable distribution. [The full adapted workflow](upstream-workflow.md)
links the task-specific references.
