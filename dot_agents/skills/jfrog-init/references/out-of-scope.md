# Setup boundaries

Portable skill installation does not install/update a plugin, Node runtime,
Agent Guard, CLI, package hook, marketplace or remote MCP. It does not choose a
platform, create a project, change IAM, launch login, migrate credentials,
retarget clients, write setup hints or modify a package-manager binding.

Those capabilities can be separate authorized tasks through their existing
native owners. Source resources and imperative examples are not permission to
execute them. Preserve selected versions, trust/configuration owners and actual
permission denials; missing preferred tools remain explicit capability gaps.
