# Resolve missing information with native conversation

Use known project/configuration evidence first. Ask only when missing target,
project, artifact identity or authority would materially change the next action.
Use the current harness's available question facility or a concise plain question;
do not call a nonexistent Claude-specific tool or force an exact JSON prompt.

Preserve previously granted concrete task authority. Surface what the proposed
change touches and why missing information matters. Do not hide installer methods,
paths, required versions or side effects behind a generic yes/no prompt. Never ask
for credentials in chat; existing native authentication owns secret entry.
